# Eyes Heal

A 4-minute guided eye exercise workout in a single HTML file — no build, no dependencies.

## Exercises

1. Slow blinking
2. Left & right
3. Up & down
4. Eye circles
5. Near & far
6. Look far away
7. Palming
8. Squeeze & release

Voice cues guide you through each step and can be muted.

## Usage

Use it online at https://vb1lyi.github.io/eyesheal2/, or open `index.html` in any modern browser.
